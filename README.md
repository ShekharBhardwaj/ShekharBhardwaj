#### How I build

- **Measured, not promised.** Performance claims trace to a script you can rerun; cost math is pinned by tests against real provider bills.
- **User zero eats the bugs first.** Nothing ships until its primary scenario passes under my own hands, and every mess my machine produces becomes a product fix so yours never sees it.
- **Small releases, honestly named.** Ship what is stable, say what is missing, let the changelog tell the truth.
- **Plain words.** If a feature needs jargon to sound useful, it is not ready.
